# Archive

This directory keeps old configuration experiments that are useful as reference,
but are no longer part of the active dotfiles setup.

## Neovim

The active Neovim configuration is `../nvim-lazy`.

The `neovim/` directory contains previous configs such as `nvim-packer` and
`nvim-kickstart`. They remain tracked for history and reference, but Telescope
and ripgrep ignore `archive/` during normal searches so they do not pollute
day-to-day results.
